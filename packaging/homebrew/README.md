# Homebrew tap

These files are the contents of a tap repo, `Himanshu-Sangshetti/homebrew-twinfold`. They are regenerated for each
release with `scripts/homebrew.sh VERSION`, which reads the checksums the release workflow publishes.

Once the main repo is public:

1. Create `github.com/Himanshu-Sangshetti/homebrew-twinfold` and copy `Casks/` and `Formula/` into it.
2. Then people can install with:

   ```sh
   brew install --cask himanshu-sangshetti/twinfold/twinfold   # the app
   brew install --formula himanshu-sangshetti/twinfold/twinfold       # the command line tool
   ```
